# OpsCore

OpsCore is a modular operations platform combining IT service management, infrastructure management, and compliance operations.

## Modules

- OpsCore Service — incidents, requests, problems, changes, SLAs and knowledge
- OpsCore Infrastructure — server rooms, racks, equipment and physical infrastructure
- OpsCore Compliance — DCAM-aligned compliance, inspections, evidence and actions

## Architecture

- React + TypeScript web app
- Node.js + TypeScript API
- PostgreSQL-ready data layer
- Docker-first deployment for TrueNAS

Initial v1 bootstrap.
